# 五子棋 · 3D

基于 [three.js](https://threejs.org/) 的 3D 版五子棋（Gomoku）MVP。纯前端、零构建、零依赖安装——three.js 已本地化到仓库，离线可玩。

## 效果

- 对手可选：人类双人 或 AI（你执黑先行，启发式评估：攻击分 + 0.9×防守分，赢棋/堵杀优先）
- 木纹 3D 棋盘（canvas 程序化纹理：15×15 网格 + 5 个星位）
- 棋子 3D 落下动画（缓动 + 阴影）
- 自由视角：拖拽旋转 / 滚轮缩放
- 悬停显示半透明"幽灵"棋子预览落点
- 胜负判定：四方向五连（含长连）、满盘平局
- 获胜时五连棋子上叠加脉动金色高亮环

## 运行

ES modules 需要通过 http 协议访问（直接双击 `index.html` 会因 CORS 失败）：

```bash
cd E:/_OUTPUT/five   # 或本仓库任意检出目录
node serve.js        # 默认端口 8322，换端口：PORT=8000 node serve.js
```

浏览器打开 `http://127.0.0.1:8322/`。

其他任意静态服务器（`npx serve .`、`python -m http.server` 等）也可。

## 操作

| 动作 | 效果 |
|---|---|
| 拖拽 | 旋转视角（不算落子） |
| 滚轮 | 缩放 |
| 鼠标移入交叉点 | 显示当前行棋色的幽灵棋子 |
| 单击交叉点 | 落子 |
| 「新对局」按钮 | 清盘重开 |

规则：15×15，黑先，先连成五子（任意方向、长连也算）者胜；225 手满盘无五连为平局。

## 对手模式

HUD 中「对手」下拉框切换：

- **人类（双人）**：默认，两人共屏轮流落子
- **AI（你执黑先行）**：AI 执白，落子延迟 0.4s 模拟思考；你的回合外（AI 思考中）点击落子会被忽略。切换模式自动重开一局

AI 为启发式评估（非搜索树）：候选点取全部棋子 2 格邻域内的空格，逐点计算「己方攻击分 + 0.9 × 对方威胁分 + 中心倾向」，优先级为 成五 > 堵对方成五点 > 综合分最高。分制：活四/冲四 50000/5000、活三 3000、活二 200——会堵活三、活四，但强度约业余水平。

## 文件结构

```
├── index.html              # 页面 + HUD
├── main.js                 # 全部逻辑：3D 场景、拾取、游戏规则、AI 接入
├── ai.js                   # AI 走子（启发式评估，纯函数，无 DOM 依赖）

├── three.module.js         # three.js r160（本地化，离线可用）
└── vendor/OrbitControls.js # OrbitControls（本地化）
```

## 实现要点

- **拾取**：射线投射到棋盘平面后取最近交叉点（`Math.round`），无需 225 个不可见碰撞体
- **拖拽/点击区分**：位移 > 6px 或时长 > 400ms 判定为相机拖拽，不触发落子
- **纹理**：`makeBoardTexture()` 在 1024×1024 canvas 上画木纹 + 网格 + 星位，一次生成
- **胜负**：每落一子从落点向四个方向双向延伸计数，O(1) 级判定
- 调试：浏览器控制台无预留接口；如需自动化可临时暴露 `window.__five`
